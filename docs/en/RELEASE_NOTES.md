# Practice Helper v1.0.1 — English

Standalone English interface, status and error messages, and documentation. Gameplay and hotkeys are unchanged from v1.0.0. Includes the red-moon background, P icon and themed window frame.

Download the self-contained ZIP if you do not have .NET 9 Desktop Runtime x64. Extract all files before launching. All assistance starts disabled. Keep assisted scores and replays separate from normal clears; live-game testing remains incomplete.

This is an unofficial, AI-assisted personal project. Background inclusion does not grant an additional reuse license. Read README.md for the supported game hash, controls and limitations. Repository visibility is unchanged.
