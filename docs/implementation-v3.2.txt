新典练习辅助 v3.2 — 自用实验版

增量功能：0.25×–2× 整体变速；移除全部关闭按钮及 F12 注册；不限制得分。
资源／无敌／和平／时停沿用 v3.1。详见 README.md。

变速依据（精确支持的 EXE 哈希见 README）：
主循环 45D82 调用 3BE80 执行逻辑链，45E91 绘制，45E96 调用 3C330 呈现与帧调度。
3C750 初始化计时器，在 3CBC1 将计时频率 / 60（带舍入，下限 1）写入 C22100。
3C488 读取 C22100，结合 C22128（起点）及 C22130（帧计数）计算下一帧截止时刻。
3C4D6 至 3C59F 使用游戏的时钟／等待函数完成睡眠和自旋等待。

新增挂钩：RVA 3C465，原指令 44 38 3D B4 5C BE 00。
它在原始调度计算前，以游戏线程更新 period = originalPeriod * 100 / percent。
倍率变化时清零 C22120（计时器初始化标记），交给原生代码重设起点和帧计数，避免旧累计帧数导致突然快进或长时间等待。
不修改每个对象的速度，不挂钩全局 QPC，不修改渲染器垂直同步，不触碰成绩地址，不改音频播放速度。

控制块新增字段：+12 int 目标百分比，+16 int 速度心跳，+24 long 原始间隔，+32 long 上次写入间隔，+40 byte 基线有效，+44 int 已应用倍率。
范围 25–200；只有 scene 2 应用倍率，其他场景暂用 100。原生重新初始化产生新的间隔时重新捕获基线。
UI 显示“已应用”指间隔参数已设置，不是经过墙钟实测达到该帧率。垂直同步、性能和原生快进均可能影响实际结果。
心跳由 UI 续期、渲染帧递减；到期恢复 100%。正常退出则暂停线程，立即恢复自己持有的原间隔并重置调度，再移除代码挂钩。
如间隔已被外部改写，退出不会用旧值覆盖外部值。不要同时运行其他修改器。

新增验证：
SpeedSelfTest 执行原生倍率挂钩、边界拒绝、基线重建、跨面／菜单、心跳到期、还原和模式独立性。
进一步运行游戏原生截止时刻与自旋等待代码，使用确定性时钟，验证 50/75/100/150/200% 六帧耗时比例。仅私有映像里跳过绘图和无关 HUD。
RemoteModeTest 的独立进程同时持续执行玩家与变速挂钩，测试跨进程安装、半速、场景转换、超时以及卸载后原间隔恢复。
测试不操作真实游戏。完整实机表现（所有自机、关卡、暂停、后台、垂直同步、音画、录像）未保证。

快捷键仍为 F5–F11，F12 完全不注册。内部 DisableAll 只用于退出／错误／重新连接的清理，不提供全部关闭按钮或热键。
