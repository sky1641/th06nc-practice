# 新典练习辅助

版本 1.0.1 — 中文版

适用于 Windows x64 的非官方练习与观光辅助，开发过程使用了 AI，不隶属于游戏开发者或 thprac。无需账号，没有广告或联网功能。启动时所有辅助默认关闭。

## 开始使用

完整解压后运行 TH06NCTrainer.exe，保留同目录的全部文件。普通包需要 .NET 9 桌面运行时 x64；自包含包已附带运行时。先正常关闭旧版，再启动游戏并进入一局。中英文版控制同一个游戏，不可同时运行，程序会阻止重复启动。

仅支持 SHA-256 为以下值的 Steam 新典 th06nc.exe：

`07850C8C6E469C0E82C13423E6D0D096A88D693455BDACACBB44C0AA3BCCE473`

## 快捷键

| 按键 | 功能 |
| --- | --- |
| F5／F6／F7 | 锁残机／Bomb／POWER；“设置一次”只写入一次目标值。 |
| F8 | 无敌，免疫普通弹、敌机接触和激光伤害。 |
| F9 | 和平观光，抑制敌弹、激光和发弹音效。 |
| F10 | 选择或关闭可攻击的咲夜模式。 |
| F11 | 选择或关闭不可攻击的咲夜模式。 |
| 游戏放雷键 | 选择咲夜模式后切换时停；一般是 X，不是字母 B。 |

残机与 Bomb 目标范围为 0–8，POWER 为 0–128。目标值保存在本地 settings.json，但不会自动启用辅助。

两种咲夜模式互斥，时停不消耗 Bomb，零 Bomb 也可使用。时停中仍能移动；不可攻击模式还会暂停自机射击。和平观光与咲夜模式跨面、重试保留；过面、对话、重生、原生放雷状态以及首领换阶段会恢复当前时停。返回标题会关闭这两种模式，不修改敌机咲夜原生时停标志。

## 速度与透明度

常规速度为 25–200%。加速前关闭 V-Sync（垂直同步），也要检查显卡驱动的强制同步；音乐原速播放。所选速度跨面保留，菜单和加载使用正常速度，重开辅助后不保留倍率。

Overdrive 为手动开启的娱乐模式，目标 16 倍，按正常 60 帧折合约 960 帧；实际速度受性能和显示设置影响。这是有上限的加速，不是原版无上限漏洞。取消后恢复常规倍率，选择速度预设也会退出该模式。

自机与敌机弹幕透明度分别调整：0% 隐藏，100% 原样显示。包含敌机激光，不包含自机 Bomb 演出；不改变碰撞，所以看不见的子弹仍有危险。透明度跨面保留，重新连接或重启后恢复默认。和平模式保留音乐、拾取和菜单声音；共用发弹音效编号的其他效果也可能被静音。

## 安全与限制

只修改进程内存，不写游戏程序或存档；游戏自身仍可能保存成绩、解锁或成就。没有成绩隔离，也不人为限制得分。辅助成绩请和正常挑战区分，录像可能失去同步。

请正常关闭辅助以恢复修改。如果恢复失败，先退出游戏再关闭辅助。错误详情记入 error.log。帧计数超时恢复仅为备用：通常 120 帧，Overdrive 下 1920 帧，不覆盖旧版无敌补丁；实际帧率较低时恢复会更慢。

自动界面测试和隔离内存测试不能代替完整实机测试。不同自机、激光、连续过面、焦点切换、手柄、显示设置和录像仍需更多验证。反馈请注明游戏版本、启用功能及复现步骤，不要上传游戏本体、存档或账号凭据。
