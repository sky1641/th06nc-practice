# Regression tests

Automated checks cover language selection, UI painting, window styling and practice features in isolated memory images and a test host. Tests do not connect to a live game session and do not replace live gameplay testing.

The tests are compiled with the helper to support its self-test commands. Run them using [test.ps1](../scripts/test.ps1); see [build and test instructions](../docs/development/README.md) for details.
