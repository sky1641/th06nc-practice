# TH06 New Classic Practice Helper v1.0.0

First stable release, promoting development build **3.4.3** to application version **1.0.0** with no gameplay changes. Repository visibility is unchanged.

首次正式版：将开发版 **3.4.3** 整理为程序版本 **1.0.0**，玩法功能不变，仓库可见性不变。

## Included / 功能

- Lives, Bomb and POWER set/lock controls (F5–F7)
- Invincibility and peaceful sightseeing (F8–F9)
- Sakuya time-stop modes toggled by the in-game Bomb action (F10–F11)
- 25–200% speed control and optional 16× Overdrive entertainment mode
- Independent player/enemy projectile opacity controls
- Red-moon UI, distinct P icon and Windows 11 themed frame
