# Application source

The project file is `TH06NCTrainer.csproj`.

- `Program.cs`, `Theme.cs`, `WindowFrame.cs`: interface, controls and window appearance.
- `L.cs`: English and Chinese interface text selection.
- `MemorySession.cs`, `RemoteModes.cs`, `ModeCode.cs`, `SpeedControl.cs`: supported-game checks and practice features.
- `PracticeIcon.cs`: the independent P icon.

See [build instructions](../docs/development/README.md). Source files are not required to run a downloaded release.
