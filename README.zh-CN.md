# 东方红魔乡：新典练习辅助

[English](README.md) | 简体中文

适用于 **TH06 New Classic** 的 Windows x64 练习与观光辅助。默认关闭各项辅助功能，界面为简体中文。

当前正式版为 **v1.0.0**，由开发版 **3.4.3** 整理而来，玩法功能不变。详见[发布说明](RELEASE_NOTES.md)。

使用 AI 辅助开发的个人项目，不是官方工具，也不隶属于 thprac。没有联网、广告或账号要求，暂未选定再使用许可证。正式版包含用户提供的红月背景，见[素材说明](assets/README.md)；练习器使用独立的红底 P 图标，与游戏本体区分。

## 开始使用

1. 解压程序包，保留目录内全部文件。标准版需要 **.NET 9 Desktop Runtime x64**；自包含版附带运行时。
2. 正常关闭旧版辅助，启动本程序和 Steam 中的新典，进入一局。
3. 连接成功后按需启用。不要同时运行修改同一游戏指令的其他工具。

只支持以下 SHA-256 对应的 `th06nc.exe`，其他版本会拒绝连接：

`07850C8C6E469C0E82C13423E6D0D096A88D693455BDACACBB44C0AA3BCCE473`

## 操作

| 操作 | 功能 |
| --- | --- |
| F5 / F6 / F7 | 锁残机 / Bomb / POWER，也可只设置一次。残机、Bomb 为 0–8，POWER 为 0–128。 |
| F8 | 无敌：免疫普通弹、接触与激光伤害。 |
| F9 | 和平观光：清除并禁止敌弹、过滤发弹音效，免接触伤害。 |
| F10 | 选择或关闭可攻击咲夜模式。 |
| F11 | 选择或关闭不可攻击咲夜模式。 |
| 游戏放雷键 | 咲夜模式下切换时停，不消耗 Bomb，0 Bomb 也可使用。 |

放雷键通常为 **X**，不是字母 B。F10/F11 选择互斥的模式，不直接触发时停。时停中可以移动；不可攻击模式同时冻结自机射击。

和平与咲夜模式跨面、重试保留，但过面解除本次时停。对话、自机重生、已有原生 Bomb、Boss 换阶段时也会恢复时间。返回标题后关闭这两个模式。不修改敌方咲夜的原生时停标记。

和平模式保留音乐、拾取与菜单音效，死亡、爆炸等声音仍可能响起。特殊演出复用发弹音效时，也可能被一起静音。

## 变速与 Overdrive

在“游戏速度”设置 **25–200%** 并点击“应用”，或直接选择倍率。**加速前请关闭 V-Sync（垂直同步）**，也要留意显卡驱动的强制同步设置；本工具不会替你更改显示设置。

- 变速作用于整帧节奏，包括移动和游戏内计时；音乐保持原速。
- 所选倍率跨面保留；标题与加载期间使用正常速度。
- **Overdrive · 娱乐** 为独立手动开关，目标 **16×**，按 60 FPS 基准约为 **960 FPS**。这是有上限的高速模拟，不是原版无上限漏洞，也不保证实际达到该帧率。
- 取消 Overdrive 恢复此前常规倍率；选择任意倍率会退出 Overdrive。“恢复 1×”恢复原速，不影响其他辅助功能。
- 实际速度受性能、垂直同步、渲染等待及游戏原生快进影响。界面显示目标值，不是实测帧率。倍率不会保存到下次启动。

## 弹幕透明度

分别设置“自机”和“敌机”的 **0–100% 可见程度**，点击“应用”。**0% 隐藏，100% 保留原始显示**；“恢复”将两者还原到 100%。

仅缩放绘制时的 Alpha，保留 RGB 配色和游戏已有的渐隐效果。敌机激光也包含在内；不影响自机本体、背景、HUD 和道具。自机 Bomb 演出不在调节范围内。

透明度不改变碰撞、伤害或运动。**完全透明的子弹仍然有判定**，0% 不是和平模式。设置跨面保留，重新连接或重开辅助后恢复默认。

## 安全与验证

- 只修改进程内存，不写游戏 EXE 或存档；游戏本身仍可能保存成绩、解锁或成就。没有成绩隔离，也不人为限制得分。
- 辅助游玩的录像可能失同步，成绩请与正常挑战区分。
- 请正常退出辅助以恢复修改；恢复失败时先关闭游戏。帧计数超时保护只是备用措施：通常为 120 帧，Overdrive 开启时为 1920 帧；实际帧率低时恢复较慢。旧版无敌补丁不受此保护。
- v3.4 覆盖判定点跟随、透明度分类与 RGB 保持、支持 Alpha 的绘制分支、Overdrive、原有玩法和安装／卸载测试。新增“测试游戏先退出，再执行练习器实际关窗处理”的回归。测试使用私有映像和独立进程，**不等于实机游玩测试**。
- 尚待实机回归：所有自机、激光、连续过面、时停中切换低速、显示设置、手柄与录像。透明度的实际画面及 Overdrive 实测速度仍需游戏中确认。
- 恢复异常记录到本地 `error.log`。游戏已经结束时无需再恢复其内存，不再因此阻止练习器关闭。游戏仍运行且恢复失败时，保留恢复所需句柄以便重试。

## 构建与自测

Windows x64 安装 .NET 9 SDK，在仓库目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

生成 `artifacts/app/TH06NCTrainer.exe`。构建不需要游戏文件，也不会连接游戏。隔离测试只针对自己安装的游戏：

```powershell
dotnet build .\TH06NCTrainer.csproj -c Release
.\bin\Release\net9.0-windows\TH06NCTrainer.exe --self-test "游戏完整路径\th06nc.exe" "报告完整路径.txt"
```

[v3.4 实现说明](docs/implementation-v3.4.md) 记录透明度与退出修复；[v3.3 说明](docs/implementation-v3.3.md) 保留原版“千帧乡”的机制依据。Overdrive 备注为“还原千帧乡（笑）”，实际仍是有上限的 16× 加速。

正式版嵌入 `assets/background.png` 红月背景；开发构建缺少该文件时使用深色底。`icons/practice.ico` 及矢量绘制源码 `PracticeIcon.cs` 提供 16–256 px 的独立红底 P 图标，不使用游戏人物素材。运行 `build-release.ps1` 可构建两种发布包、执行界面测试并生成 SHA-256 校验文件。背景权利与独立 P 图标分开说明，见素材说明。

v3.4.3 在 Windows 11 下使用近黑色原生标题栏、浅色标题和暗红色细边框；失去焦点时边框和标题文字变淡。保留系统窗口按钮、拖动缩放与正常关闭恢复流程。高对比度下恢复系统边框配色；较早 Windows 保留标准外框。只改变练习器窗口，不更改系统或游戏主题。详见 [边框说明与测试范围](docs/implementation-v3.4.3.md)。

v3.4.1 未解决用户实机反馈的叠字。v3.4.2 改用不透明文字／容器背景，开关文字使用与背景一致的 GDI+ 裁剪及坐标变换，并保证禁用文字可读。可运行 `TH06NCTrainer.exe --ui-self-test "报告完整路径.txt"`，检查背景不透明、裁剪／位移、多次脏背景重绘、启用／禁用及勾选状态、三种字体尺寸。离线预览覆盖普通与加宽窗口；这些检查不连接游戏，也不能代替真实桌面的缩放、遮挡恢复与多显示器 DPI 验证。详见 [v3.4.2 说明](docs/implementation-v3.4.2.md)。反馈请说明游戏版本、启用功能和复现步骤，不要上传游戏本体、存档或账号凭据。
